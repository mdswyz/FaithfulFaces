# FaithfulFaces

Project webpage for **FaithfulFaces: Pose-Faithful Facial Identity Preservation for Text-to-Video Generation** (NeurIPS 2026).

[Paper](https://arxiv.org/abs/2605.04702)

This repository contains the static project website. Research code is coming soon.

## Website updates

Edit `index.html`, `style.css`, or the files in `assets/` and push to `main`. Configure GitHub Pages to publish from `main` and `/ (root)`.
